04 / REFLECTION · UI DESIGN

让复杂信息有层次，
让每一步选择更清晰。

这个项目中，我关注的不只是卡片的样式，
而是如何在连续的商品流里，建立一套清晰、一致、可延续的 UI 语言。

01

信息层级

让排名、型号与价格各有优先级，在高密度信息中建立清晰的阅读顺序。

02

组件一致性

用一致的图片尺度、对齐与留白，组织榜单、品牌和价格卡的不同形态。

03

交互连续性

串联列表入口、筛选浮层与条件回显，让用户始终看得懂当前状态。

我的 UI 设计思考：在视觉表达与浏览效率之间，找到恰当的分寸。
