# Apple Chen 作品集网页

这是从原始单文件 HTML 拆分出的可部署网页版本。视觉样式、鼠标效果、滚动动效、项目切换、加载页和返回逻辑均保留。

## 目录

- `index.html`：网站首页（部署入口）
- `resume.html`：简历页
- `projects/`：8 个独立项目页
- `assets/images/`：页面图片
- `assets/fonts/`：本地字体与字体样式
- `.nojekyll`：让 GitHub Pages 直接按静态文件发布

## 性能版本说明

- 原始约 177 MB 单文件已拆成首页、简历和 8 个按需加载的项目页。
- 首页不再通过 `srcdoc` 同时解析多个完整项目网页。
- 首页首屏以下的图片采用延迟加载；项目推荐卡使用静态 WebP 封面。
- 大尺寸 PNG/JPG 与超大 WebP 已按网页实际显示尺寸重新编码。
- 未被任何页面引用的旧素材不会进入生产发布包。

## 本地查看

不要直接双击 `index.html`。请在此目录启动本地服务器：

```bash
python3 -m http.server 8000
```

然后浏览器打开：`http://localhost:8000`

## 部署原则

上传时必须保留整个目录结构，不能只上传 `index.html`。静态托管平台应把本目录设置为发布目录。
